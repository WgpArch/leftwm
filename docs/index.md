# Welcome to LeftWM Dotfiles

This is my personal LeftWM configuration for Arch Linux running on X11.

## What's Included

- **LeftWM** - Dynamic tiling window manager
- **Polybar** - Floating status bar with custom modules
- **Rofi** - Application launcher with custom theme
- **slock** - Simple screen locker
- **nm-applet** - Network manager system tray

## Color Scheme

- **Border**: `#C36C0F` (Amber)
- **Text**: `#ED9381` (Coral)
- **Background**: `#0a0a0a` (Deep Black)
- **Highlight**: `#FFB86C` (Light Amber)
