# Keybinds Reference

All keybinds use `Mod4` (the Super / Windows key) as the primary modifier.

## 🚀 Applications & System

| Keybind | Action |
| :--- | :--- |
| `Mod4 + p` | Open Rofi Application Launcher |
| `Mod4 + Shift + Return` | Open Terminal (lxterminal) |
| `Mod4 + Shift + q` | Close focused window |
| `Mod4 + Shift + r` | Soft Reload LeftWM & Polybar |
| `Mod4 + Shift + x` | Log out / Kill session |
| `Mod4 + Ctrl + l` | Lock screen (slock) |
| `Print` | Take a screenshot (3-second delay) |

## 🪟 Window Management

| Keybind | Action |
| :--- | :--- |
| `Mod4 + Return` | Move focused window to top of stack |
| `Mod4 + Shift + k` | Move focused window up in stack |
| `Mod4 + Shift + j` | Move focused window down in stack |
| `Mod4 + Shift + Up` | Move focused window up (arrow keys) |
| `Mod4 + Shift + Down` | Move focused window down (arrow keys) |

## 🎯 Focus & Navigation

| Keybind | Action |
| :--- | :--- |
| `Mod4 + k` | Focus window up |
| `Mod4 + j` | Focus window down |
| `Mod4 + Up` | Focus window up (arrow keys) |
| `Mod4 + Down` | Focus window down (arrow keys) |
| `Mod4 + l` | Focus next workspace |
| `Mod4 + h` | Focus previous workspace |
| `Mod4 + Right` | Focus next workspace (arrow keys) |
| `Mod4 + Left` | Focus previous workspace (arrow keys) |
| `Mod4 + w` | Swap tags |
| `Mod4 + Shift + w` | Move window to last workspace |

## 📐 Layouts

| Keybind | Action |
| :--- | :--- |
| `Mod4 + Ctrl + k` | Next layout |
| `Mod4 + Ctrl + j` | Previous layout |
| `Mod4 + Ctrl + Up` | Next layout (arrow keys) |
| `Mod4 + Ctrl + Down` | Previous layout (arrow keys) |

## 🔢 Tags (Workspaces)

*Note: LeftWM is configured with 15 tags in this setup.*

| Keybind | Action |
| :--- | :--- |
| `Mod4 + [1-9, 0, F1, F2]` | Go to specific tag |
| `Mod4 + Shift + [1-9, 0, F1, F2]` | Move focused window to specific tag |
